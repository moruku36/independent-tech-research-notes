## 読むときの注意

- **資料の種類：** 学術論文・プレプリント、企業記事、個人の実践記事、企業開示を区別しています。
- **確認状況：** 一次資料の確認、本文の精読、結果の再現は別の状態です。範囲は各ノートを参照してください。
- **活用案：** 実務への適用案・研究計画は、実施・検証済みと明記されていない限り提案です。
