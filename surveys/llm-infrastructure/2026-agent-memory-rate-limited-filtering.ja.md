# エージェント記憶：履歴の再読から現在状態の維持へ

## 概要

- **何についてのものか**: 変化するイベントから現在の権限を答える合成ベンチマーク。
- **何を述べているか**: モデルでイベントを解析し、決定的規則で状態を更新する。全文ログに対する優位は読取モデルと履歴長に依存する。
- **留意点**: 既知の規則・合成領域での結果で、依存関係を使う検索が同等になる条件もある。

## 実務向け6行

- 問いは、変化する履歴から現在の権限を正しく保てるか。
- モデルのイベント解析と、決定的規則による状態更新を分ける。
- 検証条件では全文ログより長い履歴に耐えるが、限界は読取モデルに依存する。
- 応用案は、タスク状態と承認変更を再生可能な構造化イベントにすること。
- 更新規則を版管理し、生履歴・状態・依存関係検索で比較する。
- 既知規則の合成課題であり、検索全般への普遍的優位を示さない。

## 方法・根拠と限界

決定イベントの順序や値だけを変えた対を、実行可能な規則で採点する。モデル解析＋明示更新は256イベントで80〜89%。正解状態を与える条件とは別。順序を無視する保持方式の限界を、全文読取一般の不可能性と解釈しない。
