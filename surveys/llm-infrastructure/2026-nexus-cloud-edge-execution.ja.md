# Nexus：クラウド・エッジ・端末をまたぐ実行と権限

## 概要

- **何についてのものか**：エージェント向けのクラウド・エッジ実行基盤。
- **何を述べているか**：永続識別で端末権限・復旧・結果を対応付ける。
- **留意点**：管理下試験から全外部操作の厳密な一回実行は保証できない。

## 実務向けの読み解き（6行）

- 永続する呼出を作業の単位にする。
- 調査単位の委譲で選んだ端末操作を制限する。
- 完了記録を再利用して不要な再実行を減らす。
- 本ノートの提案：論理作業・試行・閲覧を分ける。
- 無料の確認は結果記録前後の故障を合成して整理。
- 記録欠損を未実行の証拠にしない。
