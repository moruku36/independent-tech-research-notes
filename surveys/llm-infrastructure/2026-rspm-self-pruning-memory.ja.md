# Let Them Sleep：RSPMの記憶整理と削りすぎの問題

## 概要

- **何についてのものか**：失敗経験を再利用可能な規則へ整理する記憶手法。
- **何を述べているか**：三つの設定で改善を報告し、記憶量も削減する。
- **留意点**：削りすぎで有用な履歴を失い、回答が悪化する場合がある。

## 実務向けの読み解き（6行）

- 経験の保存量だけでは記憶の質は上がらない。
- sleepで失敗をまとめ、経験を規則へ置き換える。
- ソフトウェア結果は実修正でなくシミュレーション。
- 本ノートの提案：原文は検索対象外に別保存する。
- 無料の確認は合成の訂正・過去状態の質問から。
- 失敗時に参照した記憶が失敗原因とは限らない。
