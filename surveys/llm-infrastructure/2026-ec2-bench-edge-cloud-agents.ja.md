# EC2-Benchによる端末・クラウド協調エージェントの評価

## 概要

- **何についてのものか** 長いエージェント作業を端末側とクラウド側で分担するベンチマーク研究。
- **何を述べているか** ルーティング、委任、助言を、完了度、資源、クラウドに見える機微情報で比べる。
- **留意点** 高能力の端末モデルには将来端末の代理も含む。実機での性能やプライバシー保証は別途評価が要る。

## 実務向けの読み解き（6行）

- 128の実行可能な課題を用意し、100課題に機微情報の注釈を付ける。
- 端末とクラウドの参加を、実行の全経路で追跡する。
- 露出指標は、クラウドの文脈に見えた注釈付き情報の割合。
- 端末側が強くなると、協調方式間の完了度の差は縮む。
- それでも方式による情報露出の差は残り得る。
- ハーネスへの応用案は、合成作業環境で端末のみ、委任、助言を比べること。

## 方法・証拠・限界

完了度は要件検査の加重集計。露出は注釈単位とLLM評価器で判定し、200組で人の判定と照合する。課題の選定では容易な課題と解けない課題の一部を除くため、結論は課題構成、モデル費用、露出と被害の定義に依存する。
