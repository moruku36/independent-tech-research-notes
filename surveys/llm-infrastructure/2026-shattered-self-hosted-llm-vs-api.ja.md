# ShatteredによるLLM自前運用とAPIの費用比較

## 概要

- **何についてのものか** モデル重みの自前運用と従量課金APIを比較する編集記事。
- **何を述べているか** Kimi K3.1 Pro、GLM-5.3、DeepSeek V4.1 Flash、Mistral Large 4を、料金・メモリ・運用条件で比べる。
- **留意点** 損益分岐の例は、クラスタ費用とトークン構成に仮定を置いた試算。

## 実務向けの読み解き（6行）

- APIの月額がクラスタの運用費を超える条件を考える。
- 公開資料を使い、入力対出力を5対1、キャッシュヒットをゼロと仮定する。
- 重み全体のサイズはメモリ見積もりに効き、活性パラメータ数は処理速度を左右する一要因になる。
- 料金・配布条件・実行基盤の対応状況は、製品と確認日をそろえて扱う。
- 応用案として、月間処理量と遅延に加え、採用できた結果1件あたりの費用を比較する。
- 複数の出所から評価スコアを集めているため、モデル間の品質差は別途確認する。

## 書誌・確認範囲

Tom Vance、Shattered、2026-11-10更新。2026-11-11 JSTに比較表・料金・損益分岐の節を部分確認。Kimiの構成はMoonshotのモデルカードと照合した。

## 手法・証拠・限界

記事の例ではクラスタ月額を3万ドルと仮定する。固定の月額費用を加重平均のAPI単価で割ると、費用が並ぶ処理量を求められる。想定稼働率と必要な遅延条件でその量をさばけるかは別に確かめる。記事の式で追加される稼働率の係数は、費用と処理容量のどちらに効くかの定義が要る。料金は記事の確認時点のもので、DeepSeekの表示価格には記事内で未解決の差がある。
