# CTFusion：開催中のCTFでセキュリティAIを評価する

## 概要
- **何か**：セキュリティ競技CTFを使ってLLMエージェントを評価する枠組みの研究。
- **結果**：著者らは、既存の静的ベンチマークでの解答率が開催中の5競技より高かったと報告する。
- **注意**：難易度とデータ混入の寄与は分離できず、対象モデル・エージェント・競技も限定される。

## 資料と確認範囲
Dongjun Lee、Ga-eun Bae、Insu Yun、[CTFusion: A CTF-based Benchmark for LLM Agent Evaluation](https://arxiv.org/abs/2605.11504v2)、arXiv:2605.11504v2、2026年7月11日改訂（初版5月12日）。arXiv書誌の題名と[HTML本文](https://arxiv.org/html/2605.11504v2)の題名「CTFusion: A CTF Based Benchmark for Evaluating LLM Agents via MCP」は表記が異なる。arXivにはICML 2026併設AIWILDワークショップ採択・カメラレディ版と記載。2026年11月2日（日本時間）に一次HTMLの抄録、設計、実験、結果、限界の主要部分を確認。コード・PDF確認と再現は未実施。

## 課題と方法
過去のCTF問題には公開解答やモデル学習時の混入があり、能力を過大評価する可能性がある。CTFusionはCTFdを使う開催中の競技とMCP経由で接続し、共有アカウントでもエージェントごとに進捗を分離する。正解のうち最初の1件だけを競技側へ転送する設計である。2025年の5つのオンライン競技、3モデル、EnIGMAとD-cipherの2エージェントを評価し、静的NYU CTF Benchの180問と比較した。

## 結果と注意
最大3回の試行（pass@3）、1試行約3ドル上限の条件で、5競技におけるGPT-4.1の平均解答率は7.10%、静的ベンチマークでは16.94%と報告される。集計範囲・課題は異なり、問題の難易度差と学習データ混入を分離・定量化できない。検索を加えた実験では公開解説や正解を取得する事例も観測したが、全ての成績差が不正や混入による証拠ではない。静的ベンチマークのEnIGMA平均は5.2節で16.8%、5.3節で16.30%と異なり、原因未確認。信頼区間を十分に算出できず点推定に留まる。

## 実務への応用案
セキュリティAIの評価では、公開済み問題だけで実力を決めず、許可された隔離環境の新しい課題も用意する。解答の出典、ツール利用、試行数、予算を記録し、課題の難度と正解漏えいを確認する。実際の攻撃能力や本番防御性能への一般化はできない。競技参加の規則と許可を守る。

## 限界
対象は3商用モデル・2エージェント・5件のCTFd競技で、時間・費用制約がある。他形式や本番環境での有効性は未確認。独立検証・再現・導入未実施。
