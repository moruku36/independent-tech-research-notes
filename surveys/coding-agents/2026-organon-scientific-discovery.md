# Organon: adapting the procedure of scientific search

## Overview

- **What it is**: An agent revises its scientific-search procedure.
- **What it says**: Reports benchmark gains from changes between bounded search horizons.
- **Caveat**: Candidate-count matching does not establish equal total cost.

## Practical reading (six lines)

- It changes search, tools, memory and worker coordination.
- History persists while the official evaluator stays fixed.
- Benchmarks report gains, not open-ended scientific autonomy.
- Our proposal: version and roll back one procedural change.
- Free check: audit a candidate/revision lineage manually.
- Do not let self-improvement rewrite the success criterion.

## Question, method, claims and evidence

The 21-task comparison caps candidate attempts at 100, with restricted candidate workers. Some tasks use additional model routing. Repeated evaluation of selected programs is not repeated independent search; neither candidate count nor the phrase recursive improvement proves unlimited acceleration.
