# AI生成コードの公開を求める論説

## 概要

- **何についてのものか**: AI生成ソフトウェアの公開方針を論じる記事。
- **何を述べているか**: 著者はOSSへの還元と人間の著作者性を理由に、オープンなライセンスやCC0を提案する。
- **留意点**: この提案だけで生成コード全般の公開義務が確定するわけではない。

## 実務向け6行

- 問いは、AI生成コードをオープンに公開すべきか。
- 著者はOSSの学習利用と人間の著作者性から論を組み立てる。
- 結論は公開方針の提案であり、普遍的な法的義務を実証していない。
- 応用案は、変更ごとに上流の出典・ライセンス・人間の確認を記録すること。
- 大量生成の前に公開方針を決め、出典不明の箇所を先に解消する。
- 法的類推は未検証で、既存repoのライセンスは変更していない。

## 方法・根拠と限界

学習元への貢献の還元を論拠とし、法域差にも言及する。提案を検証する実験はなく、法的類推の妥当性は本メモでは独立検証していない。
