# CAMP-II：文脈をまたぐファイル記憶の学習

## 概要

- **何についてのものか** 通常のファイル操作でタスク状態を保存する追加学習の研究。
- **何を述べているか** CAMP-IIは固定教師から、作業領域に記憶を書き、読み戻す方策を蒸留する。
- **留意点** 重みの追加学習を伴う。既存APIのハーネスにノートを足しただけで効果を再現したものではない。

## 実務向けの読み解き（6行）

- CAMG-IIは購買、コード、研究、一般業務、視覚の5領域を扱う。
- エピソード中の作業領域は、アクティブな文脈を置換しても保持される。
- 非同期のon-policy蒸留で、生徒自身が生成したトークンを教師が指導する。
- 4Bモデルの平均は64.6%、固定生徒は45.3%、最強のOPD比較手法は51.8%。
- 2.97倍は固定生徒からの改善量の比であり、成功率そのものの倍率ではない。
- 応用案は、構造化した継続ファイルと読み戻しの検査を今のハーネスで試すこと。

## 書誌・確認範囲

Lirui Luoほか『Coding Agent Memory Post-Training II: Unlocking the Memory Potential of Pre-trained File Operations for Long-Horizon Tasks via On-Policy Distillation』。arXiv:2611.14009v2、2026-11-12、初版2026-11-10。2026-11-14 JSTに§4〜7と表1を部分確認。会場と版間差分は未確認。

## 方法・証拠・限界

表1から(64.6 − 45.3)/(51.8 − 45.3) ≈ 2.97と読める。各領域128問と、外部2ベンチマークのネットワーク不要の部分集合で評価する。生徒はQwen3.5-4B・9B、固定教師は1つ。大規模化や複数教師への一般化は未検証。
