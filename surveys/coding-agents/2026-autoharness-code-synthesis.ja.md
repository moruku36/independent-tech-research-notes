# AutoHarness：エージェントの行動検証コードを自動生成する

## 概要
- **何か**：ゲーム環境のフィードバックから、AIの行動を検証するコードを生成・改善する実験プレプリント。
- **結果**：著者らは、145のTextArenaゲームのテストで生成した検証器が不正な手を出さなかったと報告する。
- **注意**：有限のゲーム試行での結果であり、実システムの安全性や未知の状態への保証ではない。

## 資料と確認範囲
Xinghua Lou、Miguel Lázaro-Gredilla、Antoine Dedieu、Carter Wendelken、Wolfgang Lehrach、Kevin P. Murphy、[AutoHarness: improving LLM agents by automatically synthesizing a code harness](https://arxiv.org/html/2603.03329v1)、arXiv:2603.03329v1、2026年2月10日提出。Google DeepMindの著者によるプレプリント。2026年11月3日（日本時間）に一次HTMLの抄録、方法、実験と結論の主要部分を確認。PDF・実装コードの確認、再現未実施。

## 課題と方法
AIが環境のルールに反する行動を提案する問題に対し、Gemini 2.5 Flashが行動検証コードを作成する。環境から得た合法・違法の結果やエラーを使い、複数の候補を探索しながらコードを改善する。主な方式はモデルの提案を検証し、無効なら再提案を求める。別の方式では意思決定そのものをコード化し、実行時にはLLMを呼ばない。

## 結果と条件
- 自由形式の対話など9ゲームを除く145ゲームで、検証器は各ゲーム10乱数シード・最大1000ステップの新しいテスト軌跡で合法行動率100%と報告された。有限の評価であり、あらゆる入力での正しさの証明ではない。
- 実際のゲーム評価は145件全体ではなく、1人用16ゲームと2人用16ゲーム。1人用は各20試合、2人用は各40試合で評価した。
- 全判断をコード化した別実験では、1人用16ゲームの平均報酬が0.870、GPT-5.2-Highは0.844。試行数は前者が各20回、後者は費用上各5回で、対象と条件を限定して読む。
- ルールに沿うことと、戦略が最適であること、外部操作が安全であることは別の問題である。

## 実務への応用案
AIによるクラウド変更の提案に対し、許可されたパラメータや環境条件を機械的に検証し、不合格時は再提案させる設計を検討する。生成した検証コード自体も人がレビューし、隔離環境で境界条件を試す。IAM権限、承認、監査をそのコードだけに任せない。これは応用提案であり、本番クラウド運用での効果は実証されていない。

## 限界と関連資料
各ゲーム専用の検証器で、自由形式の9ゲームは対象外。有限試行、ゲーム特有の報酬・ルール、モデルと評価条件に依存し、実装・再現・導入未実施。[自律ML開発と簡素なハーネス](2026-ml-engineering-minimal-harness.ja.md)とは異なる課題と目的のため直接比較できない。
