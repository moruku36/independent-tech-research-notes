# AGENTS.md・CLAUDE.mdの実態：公開リポジトリの指示ファイル調査

## 概要

- 観察研究のプレプリント：人気と活動条件で選んだGitHubリポジトリの、ルート指示ファイルの普及・内容・履歴を調査する。
- 22,854件中26.3%に対象ファイルがあり、プロジェクト説明と作業ルールが混在し、理由のない指示も多いと報告する。
- 実行時の利用や指示の効果を測った研究ではなく、内容分類にはLLMと人の判断のずれがある。

## 実務向けの読み解き（7行）

- AGENTS.mdとCLAUDE.mdに、OSSがどのような情報とルールを書くかを調べた研究。
- 1,000 stars以上・直近90日以内の更新などを満たす22,854件を対象にした。
- 26.3%にルートの対象ファイルがあり、プロジェクト知識、テスト、作業手順などを記載していた。
- 内容分析では、指示の74.0%に理由がないと推定するが、LLMによる分類を含む。
- 本ノートの応用案：自分の指示ファイルを、実行コマンド、適用条件、理由、更新責任の観点で棚卸しする。
- ファイルが存在する割合から、実際のAI利用率や開発成功への効果は導けない。
- 人手検証は著者1人の60文で、モデル間の一致だけを分類精度の保証にしない。

## 研究の問い

人気があり活動中のOSSプロジェクトは、エージェント向け指示ファイルをどれだけ持ち、何をどのように伝えるか。

## 手法・データ・比較条件

2026-10-16時点で1,000 stars以上、90日以内のpush、非fork・非archive、主要言語13種という条件で列挙。デフォルトブランチのルートAGENTS.md/CLAUDE.mdを大文字小文字を含めて探す。参照・重複を処理してリポジトリ単位にまとめ、LLM支援で341,852文を抽出・分類。主要な内容比率はSonnetで全指示を分類した992リポジトリの重み付き推定を使い、要素表や相関は主にHaikuの未補正分類を使う（§3）。

## 主張と証拠

対象22,854件のうち6,006件（26.3%）に対象ファイルがある。最上位star層89件では59.6%。指示の74.0%に理由がないという内容推定と、少なくとも一つ理由を書くリポジトリが82.9%という推定は分母が異なる。AI貢献の表示方針にもばらつきがある。これらは観測された記述の分類であり、有効な規則の推奨順位ではない。

## 限界・妥当性への脅威

ルート以外のネストしたファイルや、実行時に実際に読んだ指示は対象外。著者1人による人手確認は60文で、主題分野の一致は43〜50%、細かい主題は32〜37%にとどまる。検証標本は対応する原文が一致した文に限定され、途中で打ち切られている。内容の関連分析は横断的で、分類誤差・人気や言語・活動の選択を含み、因果効果を示さない。

## 関連研究との比較

[Trojan Horse](../agent-safety/2026-trojanforge-repository-poisoning.ja.md)はリポジトリ内容の実行リスクを評価し、本研究は指示文書の実態を記述する。指示の存在と強制力を同一視しない。[簡素なML開発ハーネス](2026-ml-engineering-minimal-harness.ja.md)のような統制実験とは問いが異なり、文書を増やせば性能が上がるという証拠には使わない。
