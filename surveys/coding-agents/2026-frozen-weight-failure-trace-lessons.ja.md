# 重み固定の自己改善：失敗記録の追加効果

## 概要

- **何についてのものか** 重みを固定したエージェントの周辺ノートを改善する対照実験。
- **何を述べているか** 生成した判断課題では、失敗を見たノートが対応する探索対照より4.0ポイント改善した。
- **留意点** 会話全体と未使用のツール課題では改善を実証できず、小さな効果の可能性は残る。

## 実務向けの読み解き（6行）

- 実行役はthinkingを切ったQwen3.5-9Bで、大きな教師がノートを書く。
- 対照も同じ執筆・選択手順を使い、失敗エピソードだけを渡さない。
- この探索だけで、判断課題の総改善の約60%を占める。
- 小売の両執筆役は目標ルールを知っており、ルール発見の実験ではない。
- 盲検監査はBFCLの未使用240問のうち146問に欠陥があると判定した。
- 応用案は、失敗由来の教訓を同条件の探索・中立ノート・新しい課題と比べること。

## 書誌・確認範囲

Arkid Mitra、Snehil Saluja『Agent Self-Improvement with Frozen Weights: The Added Value and Limits of Failure Traces』。arXiv:2611.11342v2、2026-11-11、初版2026-11-08。2026-11-15 JSTに§2〜4を部分確認。旧版差分と会場は未確認。

## 証拠・限界

4.0ポイントの推定値は、事前登録した有意義な改善5ポイントを下回る。選抜を通っても転移の保証にはならなかった。中立ノートが上回るという比較は探索的で、採点監査と区間推定を踏まえて読む。1モデル・2ベンチマークに一般化の制約がある。
