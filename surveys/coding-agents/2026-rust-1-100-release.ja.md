# Rust 1.100：言語・メモリ管理・Cargoの変更

## 概要

- **何についてのものか** Rust 1.100.0の公式リリース発表。
- **何を述べているか** never型とアロケータ関連の安定化、Cargoの依存関係・ビルド処理の変更を紹介する。
- **留意点** 機能と移行上の注意を扱う記事であり、この環境での性能は未測定。

## 実務向けの読み解き（6行）

- never型`!`が安定化し、2024より前のeditionでもフォールバックが変わる。
- 独自アロケータの中核機能は`Vec`と`Box`が対象で、他のコレクションへの展開は継続中。
- `DropGuard`は値の破棄時にクロージャで後処理を行う。
- Cargoは対象のビルド状況に応じて未使用依存を警告し、キャッシュ配置も変更する。
- 公開後の待機期間は任意設定で、`cargo install`と公開時刻のない登録情報は対象外。
- 応用案は、採用前に互換性、依存解決、worktree間のビルドを確認すること。

## 書誌・確認範囲

The Rust Release Team『Announcing Rust 1.100.0』、2026-11-12。2026-11-14 JSTにnever型、メモリ管理、後処理、Cargoの節を部分確認。API全体の監査と手元でのコンパイルは未実施。

## 方法・証拠・限界

未使用依存の警告はdev-dependenciesを扱わない。キャッシュ内部のパスを仮定するスクリプトは影響を受けうる。依存パッケージの公開後に待つ設定は一部のリスクを下げるが、安全性の保証にはならない。リリース側の説明として記録し、比較ベンチマークとは区別する。
