# AIのIaC変更：PRの出自・採用率・持続可能性の観察研究

- GitHubのIaC変更を、人間・従来型bot・痕跡のある非開示エージェント・開示エージェントに分けた観察研究。
- リポジトリ全体の採用率と、同じリポジトリ内で比較した採用率では見える差が変わる。
- マージは品質、sustainability smellは実消費電力・費用と同一ではなく、開示による因果効果も示していない。

## 実務向けの読み解き（7行）

- PRの作成者名だけで、人間とエージェントの仕事を完全に分類できるとは考えない。
- 単純なマージ率ランキングより、リポジトリや変更種類の違いを確認する。
- IaCレビューでは権限、公開範囲、削除、永続データへの影響を具体的に調べる。
- 自分の比較では変更規模と採用条件を揃え、閉じられた理由も記録する。
- smellの検出を、実際の費用や環境負荷の測定結果と呼ばない。
- 著者属性に関係なく、プロジェクト共通の検査を使う案がある。
- このノートではPRの再収集、検出器の実行、クラウド資源の変更は行っていない。

## 書誌・確認範囲

- 原題：Do AI Coding Agents Write Infrastructure as Code Like Humans? An Empirical Study of GitHub Pull Requests
- 著者：Amine Barrak、Emna Ksontini、Charles Wehbe。
- arXiv:2610.34613v1、2026-10-25。会場・査読採択は未確認。
- 確認日：2026-11-09 JST。抄録・HTML本文の収集、出自判定、比較、smell評価、限界を部分読了。再現パッケージの実行・内容検証は未実施。

## 方法・主な報告

2025年1月〜2026年5月の公開PRを収集。収集349,975件からcommit取得不能819件を除き、49,241リポジトリの349,156件を分類する。痕跡のないAI利用は人間側に残り得る。

非開示エージェントの全体マージ率87.4%は人間78.9%を上回るが、同じリポジトリ内では4.0ポイント低いと報告する。さらに選別したコーパスの変更種類調整では別の推定値になるため混同しない。

AWS Terraformの2,645対応ペアではsmell導入10.4%対10.3%、対応オッズ比1.02（95%区間0.83–1.25）。これは有意差が検出されなかった結果であり、品質や実費の同等性の証明ではない。

## 数値と解釈の注意

bot比率は抄録32.9%、導入の寄与説明35.8%と表記が異なる。本ノートでは分母・版の差を独立に解消しておらず、一つの確定値に統合しない。収集数とラベル付き件数も区別する。

マージには保守者の方針や人間による選別が影響し、開示そのものが採用率を下げたとは断定できない。出自検出の見落とし、LLM注釈、公開リポジトリ中心、Terraform／AWSへの偏りがある。未取得diffや検出器の未知の再現率も限界となる。
