# Ignite 2026のAzure発表：展開・運用・データ基盤

## 概要

- **何についてのものか** Ignite 2026でのMicrosoft Azureの公式発表。
- **何を述べているか** AI基盤、既存システムの刷新、運用、データサービスの発表をまとめている。
- **留意点** 提供段階は製品や機能によって異なる。

## 実務向け6行

- Foundryはマネージド環境を提供し、基盤を細かく制御する選択肢としてAKSを示す。
- Azure Catalystは既存資産の把握から移行・コード刷新までをつなぐ。
- Azure Copilotの展開エージェントとAzure Monitorのヘルスモデルは一般提供と発表された。
- Azure SRE Agentの新しい企業向け統制機能はプレビュー、Workload Centerは限定プレビュー。
- Azure HorizonDBとFabric appsは一般提供、Fabric HorizonDBはパブリックプレビュー。
- Microsoft IQのビジネスプラグインはFrontierプログラム経由で提供された。

## 書誌・確認範囲

Arun Ulag、Microsoft Azure Blog、2026年11月17日公開。11月20日 JSTに発表本文とAzure Catalystの詳細記事の一部を確認。提供段階は発表日時点。

## 根拠と限界

Azure HorizonDBとFabric HorizonDBは提供先・提供段階が異なる。記事は操作・監視機能と共通の文脈・統制基盤を組み合わせる構成を示す。いずれもMicrosoftによる説明で、実際の挙動・性能・テナントやリージョンごとの利用可否は独立検証していない。

## 応用・無料の確認案

提案／未試行。仮のデプロイと復旧の流れを必要な機能に対応づけ、提供段階、承認担当者、復旧を裏づける証拠を記録する。

活用状態は提案。導入・再現実験は未実施。
