# Anthropicの企業向けコーディングエージェント保護ガイド

## 概要

- **何についてのものか**：企業でコーディングエージェントを使う際の、Claude Codeを中心とするAnthropicの運用ガイド。
- **何を述べているか**：モデルの判断、外部で強制する制限、管理者が統一するポリシーを組み合わせる。
- **留意点**：評価結果と使える制御は、対象の版、動作モード、実行環境による。

## 実務向け6行

- エージェントは実行主体の権限を使えるため、開発者やプロセスに何が許されているかを確認する。
- 認証情報を作業ごとに絞り、ファイルと通信を制限して、操作と変更の監査記録を残す。
- モデルの訓練や分類器に加え、ルール、隔離、操作前の確認で制限を重ねる。
- 影響の大きい操作は人が承認し、管理者の設定が実際に強制される範囲を確認する。
- Anthropicが資金提供した7月の評価で、所定のClaude Code自動モードでは720試行中の成功が0件だったと紹介する。
- 応用案は、試験導入する1リポジトリで、許可範囲、影響の大きい操作、監査で確認できる内容を対応付けること。

## 書誌・確認範囲

Anthropic、2026年11月23日。2026年11月24日（JST）に、判断層、固定の制限、管理ポリシーを中心に原文を確認。引用された試験や顧客事例は独立に再現していない。

## 根拠と限界

- **対策。** 認証情報の露出、過大な権限、依存関係、プロンプトインジェクションをそれぞれ扱う。短期間で失効する作業用認証情報、ファイル・通信の制限、影響の大きい操作の承認、セッションの操作記録を挙げている。
- **適用範囲。** 分類器の判定には不確実性がある。ガイドは管理者が強制できる設定と、実行方式やモードによる例外を示す。読み取り権限、認証情報、通信ポリシーはローカルとクラウドで個別に確認する。
- **評価。** 資金提供を受けた試験では、間接的な指示混入の72シナリオを10回ずつ、2026年7月17日までに公開された版で評価した。720試行中0件はその設定での結果で、一般の攻撃成功率はこの値から分からない。

## 応用・無料の確認案

提案。架空のリポジトリと認証情報を使い、各操作を許可・拒否・要承認に対応付ける。実行後の状態と監査記録が意図した制御を示せるか、別々に確かめる。
