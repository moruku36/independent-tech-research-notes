# 複数AIによるログ解析：証拠確認と信頼度スコアを分ける

## 概要

- **何か**: Geminiとn8nを使うシステムログ解析ワークフローを記述した論文。
- **主張**: 整形・領域別解析・証拠確認・報告を分担させる。
- **注意点**: 16事例の実演とモデルの信頼度から、検知の正答率は確定できない。

## 実務向けの読み方（7行）

- 問いは、役割を分けた解析でもログの根拠を最後まで保てるかという点。
- 7層・名前付き8エージェントと記述し、整形の並列化と領域別振分けを組み合わせる。
- Gemini 2.0／2.5 Flashが解析し、ガードが引用箇所と信頼度の規則を確認する。
- 結果は3例と追加13例であり、統制された検知器のベンチマークではない。
- 応用案は、各指摘に保存済みログ行の根拠を求め、観測と推論を分けること。
- 検証案は、根拠の一致を決定的に確認し、正解ラベル付き正常ログの誤警報を測ること。
- 信頼度の上限は運用規則であり、校正された確率や実測正答率ではない。
