# Goldman Sachs’ reported restrictions on AI coding-tool access

## Overview

- **What it is** Bloomberg reporting on Goldman Sachs’ internal access rules for AI coding tools.
- **What it says** The report describes an October policy narrowing access mainly to engineers, with an exception for quantitative engineering roles called strats.
- **Caveat** The internal guidance was not available for this note, and effects on productivity or risk were not measured.

## Practical reading (six lines)

- The article names Claude Code and GitHub as tools affected by the reported restriction.
- It attributes the scope to internal guidance seen by Bloomberg and people familiar with the matter.
- Strats, whose work bridges trading, quantitative research and software engineering, reportedly retain access.
- A named spokesperson describes choosing long-term users after assessing productivity and risk.
- A proposed governance study maps access to tasks, data and review responsibility, then measures the workflow outcomes.
- The report supports a dated case study. The exact GitHub feature and full exception process remain unresolved.
